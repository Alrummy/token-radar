Entry for make.fun's “Build the best token launch radar” bounty. Build the best token launch radar. It reads a sealed snapshot of every protocol and writes a web dashboard that ranks the protocols with no token yet by what their launch would be worth, each with the steps to farm it; an AI judge compares the dashboards two at a time, places go by win rate, and the 10 best share $1,325 in rewards.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```
